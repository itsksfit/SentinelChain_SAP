# SentinelChain 🚨

### AI-Powered Electronics Supply Chain Recovery

SentinelChain helps procurement teams respond to critical component disruptions by turning a supply-chain alert into a **ready-to-approve recovery plan**.

Instead of spending days manually finding alternatives and contacting distributors, SentinelChain aims to complete the recovery workflow in **under 5 minutes**.

## 🔄 How It Works

```text
Disruption
    ↓
Detection Agent
    ↓
Impact Analysis
    ↓
Alternative Matching
    ↓
Chase / Negotiation Agent
    ↓
Recovery Plan
```

### 🤖 Four AI Stages

* **Detection Agent** — identifies the affected component
* **Impact Agent** — finds affected products and revenue at risk
* **Cross-Reference Agent** — finds compatible alternatives
* **Chase Agent** — simulates distributor outreach and ranks the best option
